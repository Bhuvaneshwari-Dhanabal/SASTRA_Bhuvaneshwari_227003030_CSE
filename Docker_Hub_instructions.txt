1. Identify your images

docker images

2. Log in to Docker Hub

docker login

3. Tag your application images

docker tag sastra_bhuvaneshwari_227003030_cse-dmfrontend:latest YOUR_DOCKERHUB_USERNAME/autosar-ai-frontend:latest

docker tag sastra_bhuvaneshwari_227003030_cse-dmbackend:latest YOUR_DOCKERHUB_USERNAME/autosar-ai-backend:latest

4. Push the images to Docker Hub

docker push YOUR_DOCKERHUB_USERNAME/autosar-ai-frontend:latest
docker push YOUR_DOCKERHUB_USERNAME/autosar-ai-backend:latest


5. Pull the images on another computer or cloud server
On the other machine, run

docker pull YOUR_DOCKERHUB_USERNAME/autosar-ai-frontend:latest

docker pull YOUR_DOCKERHUB_USERNAME/autosar-ai-backend:latest

docker pull ollama/ollama:latest

For Ollama, download the model separately on the cloud server:

docker exec -it autosar-ai-ollama ollama pull qwen2.5:3b
